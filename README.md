## 🌱 Inspiration

In the beginner-friendly spirit of **TinkHerHack 4.0**, this project was born from a simple question:

> *What if productivity tracking didn’t just store data — but actively helped you evolve?*

Most productivity tools are passive. They record actions but never interpret the human behind them.  
This leads to **data fatigue** — tracking without transformation.

**Kinetic Ledger** explores a deeper idea:

> **How can an AI agent actively balance a human's growth across multiple life dimensions?**

Instead of logging what you do, it analyzes **who you are becoming.**

## 💡 What This Project Does

Kinetic Ledger is an **Agentic AI System** that autonomously:

- 🧾 **Perceives Activity**  
  Analyzes natural language input using **Gemini 2.5 Flash**

- 🧠 **Extracts Neural Vectors**  
  Maps text into five core growth dimensions:
  - Technical  
  - Creative  
  - Social  
  - Logic  
  - Empathy  

- ⚖️ **Evaluates Equilibrium**  
  Detects imbalance or stagnation zones

- 🚀 **Issues Proactive Directives**  
  Generates “Evolution Tasks” to restore balance

---

## 🧠 Why This Is Agentic AI

The system behaves like an autonomous agent by performing:

### 🔎 Reasoning  
Determines activity weight (e.g., baking vs coding) without manual tagging.

### ⚡ Proactive Action  
Pushes a directive when imbalance is detected — instead of waiting for a user command.

### 🛡 Resilience  
If the API fails, a **Local Heuristic Engine** ensures continuity.

---

## ⚙️ How the Agent Works

1. User submits natural language input  
2. Gemini extracts dimensional weights  
3. Neural profile updates  
4. Radar chart visualizes evolution  
5. Directive engine checks for imbalance  
6. Evolution task generated if needed
